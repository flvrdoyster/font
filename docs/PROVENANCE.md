# HANKBC 출처 조사 (Provenance)

## 결론: `HANKBC.HAN` = **도깨비 디나루** 글꼴

1차 사료 [`../article.txt`](../article.txt) — 김윤수, 「글꼴 모음 #002」 (두번째 판, 1994-04-10) 에서 확정.

해당 목록의 기재:

```
도깨비 디나루     HANKBC  .HAN   도깨비 한글 3.30, 조춘형
도깨비 디나루 2  +HANKBC2 .HAN                                 :DKBDINA
```

| 항목 | 내용 |
|---|---|
| 글꼴 이름 | **도깨비 디나루** (산세리프/둥근 고딕 계열 16×16 비트맵) |
| 파일명 | `HANKBC.HAN` |
| 제작자(기재) | **조춘형** |
| 출처 | **한글도깨비 3.30** (DOS 한글 램상주 프로그램) |
| 위키백과 | [도깨비 디나루](https://ko.wikipedia.org/wiki/도깨비_디나루) (스텁): "한글도깨비에 쓰인 산세리프 비트맵 글꼴. 깔끔하고 가독성이 높아 수많은 DOS 응용에서 사용됨" |

> 이전 가설("HANKBC의 KBC = 작자 이니셜")은 **오류**. 실제로는 글꼴 이름 "도깨비 디나루"이며 작자는 조춘형.

## 우리 TTF를 이루는 3개 소스 (모두 `article.txt`에서 확인)

`name` 레코드: `BIG.ENG, HANKBC.HAN, SMD.KSG → HANKBC-ISO10646-1.TTF`

| 소스 파일 | 정체 | 출처(article.txt) |
|---|---|---|
| `BIG.ENG` | 영문 "Big" 글꼴 | line 750 `Big *BIG .ENG` (힌트 기반) |
| `HANKBC.HAN` | **도깨비 디나루** (한글) | line 309/559 조춘형, 한글도깨비 3.30 |
| `SMD.KSG` | "사임당" KS그래픽 특수문자 | line 418/804 사임당 2.0 데모 버전 |

→ 2014년 누군가 이 셋을 **wkpark(박원규)의 hfnt 도구**로 합쳐 유니코드 TTF(빈 glyf + EBDT 임베디드 비트맵)로 변환.

## 한글도깨비 배경

- 최초의 램상주형 DOS 한글 프로그램. 개발자 **최철용**, **(주)한도컴퓨터** 설립.
- 현재 단종이나 개발사가 [megalock.co.kr](https://megalock.co.kr/)에서 사후지원/다운로드 유지 중 (**개발사 현존**).
- `조춘형`은 한글도깨비의 글꼴 제작자로 김윤수가 기록 (프로그램 개발=최철용, 글꼴=조춘형).

## 라이선스 함의

1. 김윤수 모음에서 **상업사용 제한이 명시된 글꼴은 영화체(HANYH) 단 하나**. 도깨비 디나루(HANKBC)는 제한 목록에 없음.
2. HANKBC는 접두어 표시(`#/*/+/.`) 없음 → 김윤수 기준 "다른 사람의 글꼴"(수집물). 김윤수 창작 아님.
3. **핵심 주의**: 원본이 PC통신 자유배포 프리웨어가 아니라 **상용 제품(한글도깨비)에 번들된 글꼴**이며, **개발사(한도컴퓨터)가 현존**함.
4. 김윤수의 당부: 저작권 유무를 떠나 제작자를 존중해 **글꼴 이름과 제작자를 밝혀달라**.

### 대응 방향 (권장 순)

- **정확한 attribution 필수**: "원작 글꼴: 도깨비 디나루 — 조춘형, 한글도깨비 3.30 ((주)한도컴퓨터)"
- **이상적**: 한도컴퓨터(megalock.co.kr)에 복원·재배포 문의/허락 시도 (개발사 현존 → 가능)
- 한국법상 비트맵 글자체 *도안*은 저작권 보호 대상이 아니고 본 프로젝트는 벡터로 재작성하므로 OFL 배포는 법적으로 방어 가능하나, 상용 출처인 만큼 attribution + 가능하면 사전 허락이 안전.
