# HANKBC 출처 조사 (Provenance)

## 결론: `HANKBC.HAN` = **도깨비 디나루** 글꼴

1차 사료 [`../article.txt`](../article.txt) — 김윤수, 「글꼴 모음 #002」 (두번째 판, 1994-04-10) 에서 확정.

해당 목록의 기재:

```
도깨비 디나루     HANKBC  .HAN   도깨비 한글 3.30, 조춘형
도깨비 디나루 2  +HANKBC2 .HAN                                 :DKBDINA
```

| 항목 | 내용 |
|---|---|
| 글꼴 이름 | **도깨비 디나루** (문헌상 명칭; 실제 형태는 산세리프 고딕에 가까움) |
| 파일명 | `HANKBC.HAN` |
| 제작자 | **미확정** — `조춘형`은 김윤수 메모에만 등장(자기 단서 有), 권위 자료 미확인 |
| 출처(소프트웨어) | **한글도깨비** 계열 (DOS 한글 램상주 프로그램). 메모엔 "도깨비 한글 3.30" |
| 위키백과 | [도깨비 디나루](https://ko.wikipedia.org/wiki/도깨비_디나루) (스텁): "한글도깨비에 쓰인 산세리프 비트맵 글꼴" |

> 정정 이력: ① "HANKBC의 KBC=작자 이니셜" 가설은 오류(실제는 글꼴명 "도깨비 디나루"). ② "작자=조춘형" 도 **미검증** — 김윤수(1994) 수집 메모에만 있고, 그는 "비고의 출처는 내가 글꼴을 얻은 프로그램/사람이라 원 출처와 다를 수 있다"(article.txt 235–237행)고 명시. 권위 자료(pat.im, 이코노미21 등)의 한글도깨비 개발자 계보엔 조춘형이 없음.

## 우리 TTF를 이루는 3개 소스 (모두 `article.txt`에서 확인)

`name` 레코드: `BIG.ENG, HANKBC.HAN, SMD.KSG → HANKBC-ISO10646-1.TTF`

| 소스 파일 | 정체 | 출처(article.txt) |
|---|---|---|
| `BIG.ENG` | 영문 "Big" 글꼴 | line 750 `Big *BIG .ENG` (힌트 기반) |
| `HANKBC.HAN` | **도깨비 디나루** (한글) | line 309/559 조춘형, 한글도깨비 3.30 |
| `SMD.KSG` | "사임당" KS그래픽 특수문자 | line 418/804 사임당 2.0 데모 버전 |

→ 2014년 누군가 이 셋을 **wkpark(박원규)의 hfnt 도구**로 합쳐 유니코드 TTF(빈 glyf + EBDT 임베디드 비트맵)로 변환.

## 한글도깨비 배경 (검증)

- 원판 **DKBB**: **최철용(최철룡)** 개발, 1989-04 《마이크로소프트웨어》지 발표.
- **최철용이 최초 발표부터 소스를 공개** → 커뮤니티 파생판 양산: 양왕성의 **DKBY**(c.900120, 세벌식 지원), **DKBX** 등. (양왕성은 이후 한글과컴퓨터에서 아래아한글 개발)
- **중요 뉘앙스**: 1989년 잡지문화의 "소스 공개"는 소스가 공개 배포되어 파생이 자유로웠다는 뜻이며, **명시적 오픈소스 라이선스(MIT/GPL 등) 부여와는 별개**. 문헌상 명시 라이선스는 확인되지 않음. 번들 글꼴이 그 공개 소스에 포함됐는지도 미확정.

> 참고: 원판 DKBB의 상용화 주체(하드웨어 카드 판매사)는 프로그램 사업화 경로일 뿐 본 폰트 프로젝트의 계보와 무관하므로 크레딧·문서에서 다루지 않는다.

## 라이선스 함의

1. 김윤수 모음에서 **상업사용 제한이 명시된 글꼴은 영화체(HANYH) 단 하나**. 도깨비 디나루(HANKBC)는 제한 목록에 없음.
2. HANKBC는 접두어 표시(`#/*/+/.`) 없음 → 김윤수 기준 "다른 사람의 글꼴"(수집물). 김윤수 창작 아님.
3. 원 소프트웨어(한글도깨비/DKBB)는 **최철용이 소스를 공개 배포**해 파생이 자유로웠던 계보 → "파생 친화적" 성격. 단 **명시적 오픈소스 라이선스는 문헌상 미확인**.
4. 글꼴의 정확한 **작자·라이선스는 미확정** (조춘형은 미검증). 김윤수의 당부: 저작권 유무를 떠나 제작자를 존중해 이름·출처를 밝혀달라.

### 대응 방향

- **정확·겸손한 attribution**: 작자 단정 금지. 예) "한글도깨비(DKBB, 최철용, 1989 소스 공개판) 계열에서 쓰인 '도깨비 디나루' 비트맵 글꼴을 벡터로 재작성. 원 비트맵의 저작자·라이선스는 문헌상 미확정."
- 한국법상 비트맵 글자체 *도안*은 저작권 보호 대상이 아니며 본 프로젝트는 벡터로 재작성 + 원 소프트웨어가 소스 공개 계보 → OFL 파생 배포는 견고.

## 기존 복원 프로젝트 (선행 사례)

**박주완(PJW48/Juwan Park)의 "Dokkaebi Dinaru" 웹폰트가 이미 존재하며 유지보수 중.**

- 블로그: [dkbdinaru-font (2025-06-28)](https://blog.pjw48.net/2025/06/28/dkbdinaru-font/), 저장소: [JuwanPark/WebFnts](https://github.com/JuwanPark/WebFnts) (`DKBDinaru.ttf`/`.woff`)
- 방식: **벡터 아웃라인, upem=16 (1픽셀=1유닛) → 픽셀 스타일 보존**. FontForge 제작, OpenType 레이아웃(GPOS/GSUB) 포함
- 커버리지: 13,787자 (완성형 11,172 + 기타 기호 2,140 등) — **우리(12,354)보다 넓음**
- 이름/저작권: `Dokkaebi Dinaru` / `도깨비 디나루`, `2016 Dokkaebi & Hanulso & Juwan Park. Some rights reserved.`, v1.3.0 (2024-06-19)
- 라이선스: MIT 기반, 웹/출판/영상 자유, 폰트 파일 단독 유료판매만 금지. **원권리자(Dokkaebi=한글도깨비) 크레딧 명시** → 사실상 attribution 문제를 이미 처리

### 우리 원본 비트맵과의 대조 결과 (`scripts/`로 검증)

- 공통 글자 12,256자 중 **90%(11,078자)가 픽셀 단위 완전 동일** (일정한 세로 +2px 시프트 보정 시)
- 즉 **동일한 도깨비 디나루 원본 픽셀 디자인**. 베이스라인 위치(그들이 2px 아래)와 커버리지 범위만 차이.
- 결론: "충실한 복원" 목표라면 우리 작업은 기존본과 상당 부분 중복. 차별점은 (a) 원본 비트맵에서 직접 만든 독립 클린룸 파이프라인, (b) 편집 가능한 UFO 소스(파생/커스터마이징 토대), (c) 베이스라인 등 자체 설계 자유.
